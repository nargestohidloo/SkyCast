# SkyCast 🌤️

**A modern weather dashboard built with Next.js and TypeScript.**

SkyCast is a responsive weather dashboard designed to provide real-time weather information, forecasts, and weather insights through a clean and intuitive interface.

## ✨ Features

- **Current Weather:** View real-time weather conditions and temperature.
- **Hourly Forecast:** Explore hourly weather forecasts.
- **7-Day Forecast:** Check upcoming weather conditions for the next seven days.
- **City Search:** Search for cities and explore their weather information.
- **Air Quality:** View air quality information.
- **Weather Maps:** Explore weather data through interactive maps.
- **Reports:** Access weather insights and visual data.
- **Responsive Design:** Optimized for different screen sizes.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- Recharts
- Leaflet
- Open-Meteo API

## 🚀 Getting Started

First, clone the repository:

```bash
git clone https://github.com/nargestohidloo/SkyCast.git
```

Navigate to the project directory:

```bash
cd SkyCast
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
